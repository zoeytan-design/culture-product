# Tile & Trace Cultural Product Website

This is a dynamic one-page cultural product website created for the AI and Cultural Creativity final project.

## Product Concept

Tile & Trace｜花磚流光 is a premium Taiwanese cultural product concept that transforms traditional Taiwanese floral tile patterns into frosted translucent glass coasters.

## Website Features

- Light frosted glass visual style
- One-page product storytelling website
- Pinned scroll product showcase
- Interactive pattern story feature
- Material and packaging presentation
- Contact and pre-order section
- GitHub Pages compatible
- Fully responsive layout

## Files

- index.html
- style.css
- script.js
- assets/images/

## How to View Locally

Open `index.html` directly in a browser.

## How to Deploy to GitHub Pages

1. Create a new GitHub repository.
2. Upload all website files.
3. Go to Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select the `main` branch and `/root` folder.
6. Save the settings.
7. Open the generated GitHub Pages link.
